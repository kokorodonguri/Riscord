Riscord

Rust と egui で作られた、軽量で日本語対応の非公式 Discord デスクトップクライアントです。Electron を使わないネイティブアプリなので、起動が速く、メモリも少なく動きます。

GitHub でソースを見る ビルド方法

主な機能

チャット

サーバー・チャンネル・DM でのメッセージの送受信、返信・編集・削除。画像や GIF、スタンプ、埋め込みも表示します。

ボイス通話

ボイスチャンネルや DM 通話に参加。マイク・出力デバイス、プッシュトゥトーク、入力感度を設定できます。

QR コードでログイン

スマホの Discord アプリで読み取るだけ。メールアドレスとパスワード（二段階認証対応）でもログインできます。

テーマ

配色・背景画像・フォントを TOML ファイルで自由に変更。保存するとすぐ反映されます。

プロフィール編集

表示名・代名詞・アバター・自己紹介をアプリ内で変更できます。

日本語 UI

画面もエラーメッセージも日本語。Linux と Windows に対応しています。

ビルドと実行

Rust と Cargo が必要です。Linux では音声用に ALSA の開発ライブラリなども必要です。

git clone https://github.com/kokorodonguri/Riscord.git
cd Riscord
cargo run --release

詳しくは README をご覧ください。

よくある質問

Discord の公式アプリですか？
いいえ。Riscord は Discord Inc. とは関係のない、個人が開発している非公式クライアントです。
安全に使えますか？
ユーザーアカウントで非公式クライアントを使うことは、Discord の利用規約に抵触する可能性があり、アカウントが制限されるおそれがあります。利用は自己責任でお願いします。ログイン情報は Discord 以外には送信しません。
無料ですか？
はい。ソースコードは GitHub で公開しています。
