Riscord

Rust と GPUI で作られた、非公式 Discord デスクトップクライアントです。Electron を使わずに動き、約 110 個の同梱プラグインで自分好みに変えられます。日本語・英語・簡体字中国語に対応し、Linux・Windows・macOS で動作します。Android 版も開発中です。

主な機能

チャット

サーバー・チャンネル・DM でのメッセージの送受信、返信・編集・削除。画像や GIF、スタンプ、埋め込みも表示します。

ボイス通話

ボイスチャンネルや DM 通話に参加。マイク・出力デバイス、ノイズ抑制、プッシュトゥトーク、サウンドボードに対応しています。

画面共有

Linux では画面共有の配信と視聴ができます（xdg-desktop-portal と GStreamer が必要です）。Windows・macOS 版では使えません。

プラグイン

長文の自動分割、自動翻訳、ダブルクリックで返信、チャンネルタブなど、約 110 個を同梱。Lua で自作することもできます。

複数アカウント

複数のアカウントに同時にログインし、分割表示や別ウィンドウで並べて使えます。

QR コードでログイン

スマホの Discord アプリで読み取るだけ。メールアドレスとパスワード（二段階認証対応）でもログインできます。

テーマ

配色・背景画像・フォントを TOML ファイルで自由に変更。保存するとすぐ反映されます。

プロフィール編集

表示名・代名詞・アバター・自己紹介をアプリ内で変更できます。

表示言語と対応 OS

日本語・英語・簡体字中国語を選べます。デスクトップ版は Linux・Windows・macOS に対応しています。

自動更新

Windows・Linux 版は新しいリリースを自動で確認し、署名を確かめてから更新します。公開鍵を組み込まずにソースからビルドした版は更新しません。環境変数 RISCORD_NO_UPDATE を設定すると確認を止められます。複数アカウントのときは、メインアカウントのウィンドウだけが更新します。macOS 版は手動で入れ替えてください。

  • Windows：コード署名をしていないため、初回起動時に「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」から「実行」を選んでください。
  • macOS：署名・公証をしていないため、初回起動時に「システム設定 → プライバシーとセキュリティ」で起動を許可してください。画面共有と添付動画の再生には対応していません。
  • Linux：実行権限を付けてから起動します。ALSA・Vulkan・GStreamer などのライブラリが必要です。ファイル選択には xdg-desktop-portal と、デスクトップ環境に合ったバックエンドが必要です。

ソースからビルド

Rust と Cargo、CMake が必要です。Linux では ALSA・Vulkan・GStreamer などの開発ライブラリも必要です。

git clone https://github.com/kokorodonguri/Riscord.git
cd Riscord
cargo run --release --locked

詳しくは README をご覧ください。

よくある質問

Discord の公式アプリですか？
いいえ。Riscord は Discord Inc. とは関係のない、個人が開発している非公式クライアントです。
安全に使えますか？
ユーザーアカウントで非公式クライアントを使うことは、Discord の利用規約に抵触する可能性があり、アカウントが制限されるおそれがあります。利用は自己責任でお願いします。ログイン情報は Discord 以外には送信しません。ただし、Discord 以外とも次の通信をします。更新の確認とダウンロードのための GitHub への接続（Windows・Linux 版）、翻訳系のプラグインを有効にしたときの Google への本文の送信、GIF や埋め込みの画像を Tenor・Giphy・YouTube などの配信元から読み込む通信です。
BetterDiscord のプラグインは使えますか？
そのままでは読み込めません。主なプラグインは Riscord 用に作り直して同梱しています。翻訳系のプラグインは、翻訳する本文を Google に送ります。
無料ですか？
はい。ソースコードは GitHub で公開しています。

Riscord は非公式のクライアントです。Discord は Discord Inc. の商標であり、本プロジェクトは Discord Inc. によって承認・提携されたものではありません。
